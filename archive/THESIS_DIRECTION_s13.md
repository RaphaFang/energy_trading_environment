## 13.2 🔑 為什麼「各自最大化」與「聯合 LP」是同一件事

使用者要的是**六個獨立業主各自 price-taker、各自最大化**。這與聯合 LP **不衝突**,因為:

```
① 聯合 LP 的約束:所有 agent 的熱加起來 = DK2 熱需求
② 該約束的對偶變數 = 每小時的熱邊際成本 λ_heat[t]      ← LP 免費給出
③ 每個 agent 拿 λ_heat[t] + 外生電價,各自最大化自己的利潤
④ ③ 的排程 = ① 的排程,逐台逐小時相同               ← LP 對偶
```

**LP 是解法,不是模型。** 論文照 agent 版寫,程式跑聯合 LP,而 **λ_heat 變成一個新輸出**
—— 它就是 Varmelast 按成本排序時隱含在做的事。

🔴 **兩個成立條件必須寫進論文**:
1. **問題必須是凸的** —— 加整數(啟停)就有對偶間隙。這是「不做 unit commitment」的**真正理由**。
2. **熱那側也必須 price-taking** —— 辯護不是「我假設沒有市場力」,而是
   **hvile-i-sig-selv 成本回收原則 + Varmelast 的職責就是按成本排序**
   → **熱的市場力是被法規排除的,不是被假設掉的。**

## 13.3 🔑 `Cb` 為什麼不能「取代」`Cv`(但可以當基準)

抽汽機組的可行區是一塊**三角形**,兩個係數各管一條邊:

    背壓線(下界)  P = Cb·Q            斜率 +Cb   給定熱量下的最低發電
    容量線(上界)  P = P_max − Cv·Q    斜率 −Cv   給定熱量下的最高發電

**只用 `Cb` = 把三角形壓成下邊那條線**,不是「用 Cb 算出 Cv」。
🔴 **兩者對核心問題給相反符號**:接手者被迫多產 1 MW 熱 →
背壓版電力 **+Cb**(擺盪被抵銷)、容量線上 **−Cv**(擺盪被放大)。

✅ **但熱出力愈大三角形愈窄** —— 以 AMV4 參數(Cb=0.305, Cv=0.14, P_max=150)為例:
Q=150 時可調範圍 **83 MW_e**,Q=300 時只剩 **17 MW_e**。
→ **`Cb` 近似在最冷的小時損失最小,而那正是論文最在意的小時。**
🔑 與 §3 的護身符同一個結構,而且這次是幾何上直接看得出來的。

📌 EPT 反推 `Cv` 上界**失敗,照實記**:年均負載率只有 0.20–0.60(因為含夏天、CHP 跟著熱走),
容量線在年平均上根本不綁 → 上界 0.33–3.82,無識別力。唯一得到的是弱檢查:**DEA 的 0.14 沒有矛盾。**

## 13.6 🔴 歷史驗證只能做在垃圾軸

**哥本哈根網 2023–2025 六家主要業者一家都沒關**(只有 DSB 維修廠與 Ishøj Kommune 兩個 <110 TJ 退出)。
四座關掉的廠**都不在這張網上**:Thisted(DK1)/ SK Varme Slagelse(DK2 但別的網)/ Svendborg(DK1)/ Special Waste。
唯一一次哥本哈根網的退場是 **AMV3 燃煤 250 MW_e,2020-03** —— 而 varmelast 逐時熱需求從 **2021-01** 才開始,**沒有 before/after**。

➡️ **所以「先跑歷史驗證」= 跑垃圾軸的重分配規則**(2023 狀態 → 預測 2025 → 對 EPT 實測)。
**熱側的歷史驗證維持既有的排程時點診斷。**
📌 **這反過來證明兩個遊戲的切分是對的:退場事件發生在垃圾那個全國市場,不在熱這張網裡。**
